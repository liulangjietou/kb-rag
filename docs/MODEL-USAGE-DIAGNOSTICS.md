# 模型用量诊断

租户管理的「用量」入口供具有 `tenant:manage` 权限的管理人员查看。后端仍由 `ModelUsageController` 校验权限，按指定租户和上海时区月份读取现有汇总与调用明细；本次没有调整配额、计费规则或数据库结构。

## 页面口径

- 已结算和待结算预占分别展示，二者共同占用月度配额；不限额不显示有限额百分比。兼容服务端省略空剩余额度字段的响应。
- 已知成本按币种分别显示。缺少价格的调用显示「未定价」，不能解释为免费。
- 预占记录显示预占 Token 和「待结算」。失败、停止的记录仍展示已经产生的实际或保守估算用量。
- 调用详情包含输入、输出、预占、计量依据、错误分类、请求标识和来源标识。保守估算不伪装为准确输出计数。
- `OUTPUT_TRUNCATED` 明确表示输出达到长度上限且返回不完整。提供方额度不足与租户配额不足分别解释。
- 详情复用现有接口中的计量字段，不增加提示词、答案、凭据或异常堆栈查询。

## 状态和交互

按登录身份、租户和月份隔离读取状态，晚到的旧请求不得回填其他范围的数据。翻页、刷新失败会清除旧记录并提供重试入口，避免把加载失败解释为零用量。页面重新可见时重新读取，月份清空时立即隐藏旧内容。

明细表可以横向滚动，调用详情在适应屏幕宽度的弹窗中展示；关闭后焦点回到触发按钮。使用既有主题变量，保留八套主题及跟随系统设置。

## 验证与回退

`ModelUsageDrawer.test.tsx` 覆盖租户、月份、登录身份切换、权限撤回和请求乱序。`model-usage-diagnostics.e2e.ts` 覆盖计量口径、失败清空、八主题手机布局、可访问性和键盘焦点；既有 `model-usage.e2e.ts` 保留停止、估算与未知价格断言。

在 `kb-rag-web` 下执行 `npm test`、`npm run build`、`npm run lint` 和 `npm run test:e2e`。浏览器测试使用显式接口夹具，真实计量结果需另以本地服务核对。此改动只涉及前端，可回退对应前端版本，服务端数据无需回迁。
