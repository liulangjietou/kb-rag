# 首页知识待办与来源健康

首页新增当前账号可见的知识待办。点击一组事项后，详情直接显示对应知识库、标签页和服务端筛选结果；重置筛选可以恢复完整列表。

## 权限与数量

`GET /api/v1/me/knowledge-todos` 要求 `kb:read`。服务端在同一读取事务中先调用既有知识库授权服务取得当前租户、当前资源范围，再按这些知识库聚合；回收站和逻辑删除记录不参与。响应使用 `Cache-Control: no-store`，不包含凭据、原始错误或文档正文。

| 事项 | 数据条件 | 处理权限 |
| --- | --- | --- |
| 解析待确认 | 文档 `process_status=PENDING_CONFIRM` | `doc:write` |
| 文档待审核 | 文档 `publish_status=PENDING_REVIEW` | `doc:review` |
| 网页抓取失败 | 网页来源 `last_fetch_status=FAILED` | `doc:write` |
| 外部来源需处理 | 外部来源 `last_sync_status=FAILED/PARTIAL` | `doc:write` |

数量代表各类事项，同一文档可能同时满足不同事项。只有读取权限时显示“查看”，写操作继续在详情与后端入口授权。前端更换会话或知识库授权范围时丢弃旧摘要和迟到结果。

两类来源列表新增可选布尔参数 `attention_only`，默认 `false`。筛选在服务端分页前执行；网页仅取 FAILED，外部来源取 FAILED/PARTIAL。未知布尔值返回 400。

## 三个时间分别表达什么

| 字段 | 含义 | 哪些情况推进 |
| --- | --- | --- |
| `last_fetch_at` / `last_sync_at` | 最近尝试开始时间 | 本次尝试，包括失败 |
| `last_success_at` | 最近完整同步完成时间 | 网页 SUCCESS/UNCHANGED，外部来源 SUCCESS |
| `last_content_change_at` | 最近实际接入新文档或版本时间 | 上传链返回非重复内容；外部来源部分成功也可推进 |

网页 SKIPPED/FAILED、外部来源 PARTIAL/FAILED 保留之前的完整成功时间。重复内容不推进内容变更时间。旧数据没有足够证据，因此新增时间保持 NULL，页面显示“暂无记录”。所有来源时间都不证明文档已经完成解析、索引或审核发布。

时间字段通过独立 Mapper 原子取最大值，普通实体更新不写这两个字段，避免迟到同步或旧设置表单将较新时间倒写。来源结果和原有同步执行方式保持兼容：网页同步返回实际结果，外部来源异步受理只能显示“已提交”，结果通过刷新来源与对象明细查看。

## 升级与回退

1. 备份数据库，随服务端应用 V34，给两类来源表各增加两个可空 DATETIME 字段。
2. 启动新服务端并检查首页摘要、来源列表接口，再发布前端。
3. 回退到旧服务端或前端时保留 V34 新增列。旧写入不要求补充新列，不执行删除列或回填历史成功时间。

本批真实 MySQL 测试覆盖 V33→V34、旧记录保持、旧字段写入和重复迁移；它不替代整套发布的旧二进制回退与真实连接器验收。

## 本批验证范围

- 生产 Mapper SQL 的授权根裁剪、文档状态列、回收站与删除状态、来源时间单调写入。
- 实际来源服务的内容去重、UNCHANGED、失败、部分成功与扫描截断；HTTP 权限及筛选参数绑定。
- 首页四种跳转、重置筛选、只读入口、迟到请求、加载失败恢复、390/768/1440 布局及键盘操作。

来源连接器网络、模型回答质量、只重试失败对象和任务恢复属于后续独立验收项，不能由本批模拟数据测试推定通过。
