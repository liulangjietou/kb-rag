# 主题偏好与兼容性

主题菜单提供 System 随行、十二套固定色板，以及 AUTO / LIGHT / DARK 标记。新增 Ember 暖焰、Dawn 晨曦、Aurora 极光、Graphite 墨岩（深色），保留已有八套色板的名称、颜色和存储标识；默认仍为 Atlas 翡翠。深色 Graphite 使用 `graphite-dark`，已有 `graphite` 用户继续使用原浅色方案。

选择 System 后，浅色系统使用 Atlas，深色系统使用 Night。浏览器保存 `system` 这一偏好，系统变化只更新实际使用的色板；手动选择固定主题后，系统明暗变化不改变该选择。主题开关的主按钮继续按菜单中的固定色板顺序切换，从 System 开始则切至 Atlas。

本地存储键保持 `kb-rag-web:theme-preset`。页面启动脚本在 React 加载前解析偏好，主题上下文订阅系统模式及跨标签页存储事件；缺失、损坏或不可读的存储沿用 Atlas 回退。`data-theme-preference` 表示用户选择，`data-theme` 表示当前实际色板，两者仅在 System 模式下不同。

没有后端接口、权限或数据库变更。主题令牌继续统一应用到 Ant Design、正文、代码块、导航和登录外壳，封面的“企业级知识库RAG”标题保持。

自动化包含旧色板兼容、启动前明暗模式、System 实时切换和退出、刷新、跨标签页同步、键盘选择、菜单范围及对比度。全站主题矩阵统一覆盖十二套固定色板，System 的两种解析结果另行验证。界面夹具不替代业务答案质量验收。
