# 问答调试版本与流式可靠性

本次改动修复管理预览的版本选择、最小权限入口和流式结束判定，不改变对外 API 的版本标签语义。

## 版本与权限

- `GET /api/v1/app-previews` 允许 `app:read` 或 `search:debug`，只返回当前租户内、关联知识库全部可访问的版本摘要。应用管理列表仍要求 `app:read`。
- 问答调试从目录选择真实 `app_version_id`，不再提交对外接口使用的 `app_version`。切换应用或版本会结束当前本地调试对话，避免历史消息混用配置。
- 服务端在预览版本解析处检查版本属于路径应用。已有版本守卫继续检查租户；预览入口在交给异步线程前检查知识库范围。
- 管理预览使用所选配置和**当前活动语料**。对外 API 按既有已发布版本与冻结快照规则运行；历史无快照版本的兼容行为保持原样。
- 目录加载区分加载中、空目录和请求失败。失败可重新加载，错误前的输入保留。

## SSE 状态与边界

- 通用解析器按空行派发完整事件，支持 LF、CRLF、CR、跨网络块及 UTF-8 字节边界；保留协议规定的数据空格，丢弃未结束尾帧。
- 业务流驱动只接受一次 `done` 或 `error` 终态，忽略扩展事件与终态之后的数据。解析失败是失败终态。
- HTTP 正常 EOF 不代表回答成功；未收到终态时报告 `STREAM_INCOMPLETE`，页面保留已收到的内容。主动停止不显示为网络失败，也不自动重发问题。
- 消费结束或异常后释放 reader，收到业务终态后取消剩余读取。
- 本次修复不代表实现了会话持久化或服务端模型取消；这两项由后续已规划工作分别处理。

## 验证与兼容

新增测试先复现了缺失终态、CRLF、多终态、未完成尾帧以及跨应用版本误用，再验证修复。MVC 用例使用真实字段绑定和权限拦截器，浏览器用例验证版本 ID 请求、仅有调试权限的入口、版本切换、输入法和重复发送。

本批没有数据库迁移。前端依赖新增目录端点，部署时先升级服务端；如需回退，先回退前端，再回退服务端。对外知识调用与应用管理客户端继续使用原接口。
