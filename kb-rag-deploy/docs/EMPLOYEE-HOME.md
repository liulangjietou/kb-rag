# 员工首页

有 `app:use` 的用户可以在工作概览选择当前可使用的正式应用，并打开最近五个私有会话。仅有员工使用权时，首页不展示应用管理和知识库管理的空指标。管理、使用和调试权限仍独立。

`GET /api/v1/workspace/overview` 从当前授权读取正式应用目录，再在 SQL 的数量限制之前按租户、用户、应用范围和软删除过滤会话。返回 `Cache-Control: no-store`，仅包含应用使用元数据与会话摘要。打开入口或恢复原会话只发起读取，不创建会话、提交问题或重新运行模型。

最近会话按 `last_activity_at` 和主键倒序排列，表示会话活动时间；此处没有将资源创建时间或会话活动时间作为“最近访问”。数据库沿用 V28，会话正文及引用不进入首页响应。

前端区分读取中、真实空目录、空会话列表和请求失败；失败清除旧数据并提供重试。页面重新取得焦点时重读当前授权，401 回到登录，权限撤回后的旧入口和标题不继续显示。

部署先更新服务端，再更新前端。只有前端先更新时，新接口的 404 会显示为入口读取失败。回滚前端不影响后台会话；回滚服务端应同时回滚对应前端，不删除 V28 数据。
